# literature/

Your reference PDFs and documents (papers, lecture notes, advisor notes, thesis chapters).
Files here are **not committed** (see .gitignore); only this README is.

- `/research-lit "<topic>"` scans this folder automatically (first 3 pages of up to 20 PDFs).
- Only local files: `/research-lit "<topic>" — sources: local`.
- Suggested names: `firstauthorYEAR_short_title.pdf` (e.g. `li2006_state_abstraction.pdf`); notes: `notes_<topic>.pdf|md`.

**Adding a file does not update the wiki by itself.** After dropping files here, tell the agent
*"I added literature/<file>; ingest it"* (or *"ingest the new files in literature/"*), and it creates the wiki page(s).
